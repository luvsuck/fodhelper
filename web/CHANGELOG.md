## v1.3.1 (2026-10-30)

## v1.3.0 (2026-09-14)
- 新增「成品助手」独立页面：按规格名称/品牌/工厂/仓库/货架生成 store_goods 成品库存（已入库状态）
- 下拉统一支持输入搜索定位（规格、品牌、工厂、仓库、货架、层、列）
- 货架选中后按 height/width 渲染「层(X)/列(Y)」仓位下拉，提交具体坐标上架到 store_goods_shelf
- 货物编号复刻 WMS 编码规则（仓库 36 进制 + 日期 + 规格 + Redis 流水号）
- cost_price / production_cost 按「规格+工厂」成本价赋值，非标准长度按比例换算（四舍五入两位小数）
- 生成货物在 sys_remark 打「成品助手」标识，便于生命周期识别与清理
